# Liquid Space 2.0 — Subject Delete + Buy Me a Coffee

Updates in this build:
- Subjects can be deleted by long-pressing a subject card, with a confirmation dialog.
- Deleting a subject permanently removes its local files, folders, and metadata.
- The home header search icon is replaced by a Buy Me a Coffee support button.
- The supplied BMC widget script is rendered in a native WebView dialog.
- Added INTERNET permission for the BMC widget.
- Existing global search remains available through the Search your space field.
